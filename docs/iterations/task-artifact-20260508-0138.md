## 目标
每4小时自动迭代「青笺录·江湖行纪」武侠文字游戏，结合AI前沿技术调研成果。

## 调研发现
- **多智能体反思协同 (Multi-Agent Reflection Collaboration)**：2026年生产级Agent的4大主流模式之一。核心机制是智能体之间不仅各自反思，还互相审视彼此的行为与变化，形成闭环式协同优化
- **LLM Agent 架构**：「LLM + Memory + Planning + Tools」已成为标准范式，Agent逐步从"辅助插件"变为"应用本身"
- **交叉反思**：LangGraph框架中多Agent反思协同允许Agent在协作过程中自主反思自身行为，同时通过交互对其他Agent的输出进行审核与修正

## 迭代方向：AI技术应用 — 多智能体交叉反思协同

### 改动详情

**A. `backend/agent_brain.py` (+120行)**
1. 新增常量：
   - `CROSS_REFLECT_MAX_TARGETS = 4`：每次反思最多关注4个熟人
   - `CROSS_REFLECT_MIN_OBS = 2`：关于某目标至少要有2条观察才触发反思
2. 新增 `cross_reflect()` 函数：
   - 读取NPC的熟人类系网（从 `relationships.py` 的 `NPC_RELATIONSHIPS`）
   - 扫描最近30条观察记忆，统计每个熟人被提及次数
   - 对满足阈值的熟人目标，让LLM生成1~3条社交洞察
   - 洞察类型包括：对某人的判断变化、危险评估、可拉拢/需提防的信号、下一步相处策略
   - 存储为 `cross_reflection` 类型记忆，重要性基于原始观察+关系深度加权
   - 关系深度加成：挚交/交好/势同水火/暧昧线人/旧交等强关系获得额外0.5重要性

**B. `backend/memory.py` (+2行)**
- `format_memories_for_prompt` 新增 `cross_reflection` 标签：「人事察觉」
- `retrieve` 函数中 `cross_reflection` 记忆获得与 reflection/seed 同等的检索分数加成（+0.05）

**C. `backend/services/agent_service.py` (+9行)**
- `bg_reflect` 后台反思任务：在 `reflect()` 之后串联调用 `cross_reflect()`
- 形成完整的「自我反思 → 交叉社交反思」管道

### 技术亮点
- 实现了2026年前沿的Multi-Agent Reflection Collaboration范式
- 去中心化社交认知网络：每个NPC通过反思形成对其他NPC的独立判断
- 零额外依赖，完全基于现有 AgentMind + jieba分词 + JSON Mode架构
- 非阻塞：交叉反思在后台异步执行，不影响玩家交互流畅度
- 渐进式激活：只有当NPC积累足够社交观察时才会触发，避免空泛反思
