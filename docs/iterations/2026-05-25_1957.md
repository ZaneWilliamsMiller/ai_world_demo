# 迭代记录 2026-05-25_1957

## 改动概要

### 1. 🐛 Bug 修复 — raw_debug 信息泄漏
- **文件**：`backend/services/talk_service.py`
- **问题**：`apply_npc_reply()` 返回值中包含 `"raw_debug": parsed.model_dump_json()`，该字段随 API 响应泄漏到前端，暴露 LLM 原始输出（含所有状态字段）。
- **修复**：删除 `raw_debug` 字段，API 响应不再包含内部调试信息。
- **影响**：前端无感知（前端从未使用此字段），安全性提升。

### 2. 🧠 NPC 大脑升级 — 情绪惯性（Mood Inertia）
- **文件**：`backend/services/talk_service.py` — `_evolve_npc_mood()` 函数
- **原理**：参考 2025-2026 情感计算前沿（Affective Computing），引入情绪惯量机制：
  - **正性耐受**：当前效价 > 2.0 时，正面刺激效果打折（×0.7），负面刺激轻微缓冲（×0.85）
  - **负性放大**：当前效价 < -2.0 时，负面刺激效果放大（×1.3），正面刺激更难接受（×0.6）
  - **唤醒度惯量**：高唤醒（>7）时再升更难（×0.6），回落更容易（×1.2）；低唤醒（<3）时再降更难（地板效应，×0.5），从低点上升相对容易（×1.15）
- **效果**：NPC 情绪演化更贴近真实人类情感动态，避免情绪在极端值之间剧烈摇摆。
