## 改动概要

在 `backend/services/agent_service.py` 的 `bg_reflect` 中添加夜间门禁：
- 世界时辰为子时(0)、丑时(1)、寅时(2)时，自动反思跳过
- NPC 在深夜应当休息，此时触发 LLM 反思既浪费 token 调用，也产生「深夜自省」的违和叙事
- 例外：情绪唤醒度 ≥ 8.0 的 NPC 即使在夜间也允许反思（模拟失眠/夜不能寐的戏剧性时刻）
- 跳过时输出 debug 日志

### 设计理由

1. **Token 节省**：子时-寅时占全天 1/4，跳过这段时段的反思可将自动反思 LLM 调用减少约 25%
2. **叙事合理性**：深夜 NPC 自省产出与休眠状态冲突，避免凌晨三点产生「反思人生」的违和文本
3. **情感真实**：极端唤醒度例外机制让「夜不能寐」成为有意义的叙事事件而非 bug
4. **低侵入性**：仅修改 `bg_reflect` 自动触发路径，手动 `/api/agent/reflect` 不受影响
