## 修复的关键 Bug（6 处）

### Web 前端 (`static/index.html`)

| # | Bug | 影响 | 修复 |
|---|-----|------|------|
| 1 | `npc_states.forEach()` 对 Object 调 Array 方法 | JS 抛 TypeError，地图渲染崩溃 | `Object.entries().forEach()` |

### Godot 前端 (`godot/scripts/main_game.gd`)

| # | Bug | 根因 | 修复 |
|---|-----|------|------|
| 2 | `_mini_panel()` 声明返回 `Panel` 实际返回 `VBoxContainer` | 写错了 return 变量 | 返回 `p`(Panel) 而非 `vb` |
| 3 | `_add_stat_section()` 把 row+bar 加到 Panel 而非内部 VBox | `_mini_panel` 返回值类型错误导致链路断 | 改 `p`→参考改成通过 `panel.get_child(0) as VBoxContainer` 往内部 VBox 加子节点 |
| 4 | HUD label 引用 `get_child(0).get_child(1)` 指到 spacer | 子节点索引算错（应为 `.get_child(2)`） | 纠正索引 |
| 5 | `OptionButton.get_selected_id()` 回 -1（Godot 4 默认） | 无 item ID 时永远 -1，对话无法发送 | 改用 `.selected`（返回 index） |
| 6 | `_refresh()` NPC 下拉重建沿用旧 id | `get_item_text(get_selected_id())` 取不到文本 | 改用 `selected` 读 index |

## 架构改进

### 后端持久化（三层）
```
定期存档 (每5分)  →  关闭存档 (shutdown hook)  →  手动存档 (API)
        ↓                      ↓                         ↓
              saves/<player_id>.json  (JSON 完整序列化)
                         ↑
              SessionStore.get_or_create (启动恢复)
```

### 前端分层

```
              ┌──────────────────────┐
              │   FastAPI (8766)     │  ← 游戏逻辑
              ├──────────────────────┤
              │  /api/hello          │
              │  /api/move           │
              │  /api/npc/talk       │
              │  /api/npc/talk_stream│  (SSE)
              │  /api/save           │
              │  /api/load           │
              │  /api/saves          │
              │  /api/health         │
              └──────┬───────┬──────┘
                     │       │
        ┌────────────┘       └────────────┐
        ▼                                 ▼
  Web (static/index.html)       Godot (godot/)
  - fetch + SSE ReadableStream  - Autoload: ApiClient
  - 22KB 单文件                  - Autoload: GameManager
  - CSS Grid 色块地图            - ColorRect 瓦片地图
  - 暗色 CSS 主题               - StyleBoxFlat 主题
```

### Godot 单文件 UI 架构
```
main_game.gd (Control)
├── _build_login()         → 登录/新建/载入界面
├── _build_game_ui()       → 三栏布局
│   ├── TopBar             → 标题 + 存档 + 退出
│   ├── Left (360px)       → ScrollContainer > MapContainer
│   ├── Center (expand)    → 对话区 + 输入栏
│   └── Right (270px)      → HUD (体力/心气/制钱/行囊/好感)
├── _build_map()           → ASCII → ColorRect 14px 网格
├── _on_send()             → 对话发送 (await talk_to_npc)
├── _refresh()             → HUD + 地图 + NPC 列表定时刷新
└── _on_tile_click(ev,x,y) → 点击移动
```
