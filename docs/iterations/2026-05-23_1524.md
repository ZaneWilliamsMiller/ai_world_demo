## 改动概要

NPC 货柜交易系统和补货系统上线后，所有物品价格仅按地图固定溢价，缺乏动态变化，导致经济体验偏静态。本轮引入**天气驱动的动态定价**，让江湖物价真正「随天吃饭」，同时为后续天气事件铺垫基础设施。

### 核心设计

1. **双层天气系数**：
   - 全局倍率：影响全部品类（骤雨 +20%，闷热 -8%）
   - 品类修正：特定天气对特定品类影响更大（骤雨/湿瘴下药物涨幅最猛）
2. **四重乘数链路**：基准价 × 地图系数 × 天气全局系数 × 天气品类系数，极端天气下某些品类综合涨幅超 70%
3. **NPC 货柜实时感知**：商贩报价时会注明当地价格含天气浮动，对话更自然
4. **NPC system prompt 注入天气行情**：`format_economy_context()` 附带天气溢价说明，LLM 有据可依

### 天气价格一览

| 天气 | 全局倍率 | 品类浮动 |
|------|----------|----------|
| 骤雨 | ×1.20 | 食×1.25、物×1.15、药×1.10 |
| 湿瘴 | ×1.12 | 药×1.30、食×1.15 |
| 重雾 | ×1.15 | 兵×1.20、文×1.10 |
| 风急 | ×1.10 | 物×1.20、食×1.10 |
| 寒露/夜霜 | ×1.05 | 药×1.25 |
| 闷热 | ×0.92 | 食×0.85、药×1.08 |
| 薄雾 | ×1.05 | 无品类修正 |
