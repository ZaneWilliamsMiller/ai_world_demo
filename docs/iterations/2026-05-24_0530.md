# 活纸·每日迭代 — 2026-05-24_0530

## 方向
🧠 NPC 大脑升级 — 反思系统观察选择质量优化

## 改动概要

### 问题
反思（reflect）取最近 18 条观察→按重要性排序→取前 12 条喂给 LLM 生成洞察。存在两个缺陷：

1. **语义冗余**：多条关于同一事件的观察（如「甲给了银钱」「甲又给了银钱」「甲第三次给银钱」）挤占 LLM 上下文，浪费 token 且降低反思多样性
2. **时效偏差**：纯按重要性排序，一周前的「重大事件」永远压过今日的新观察，而反思更应该关注近期变化

### 改进

#### `backend/agent_brain.py`
- 新增 `_deduplicate_observations()`：基于 Jaccard 文本相似度（复用 memory.text_relevance）对观察做语义去重，相似度 ≥0.55 的归为一组，每组仅保留重要性最高的一条
- 新增 `_select_with_recency()`：综合 `重要性 × (0.6 + 0.4 × 时效衰减系数)` 排序取 top_k，让近期观察获得适度加权（4 小时半衰期）
- `reflect()` 采样量从 k=18 提升到 k=24（去重后仍有足够样本），流程改为：取 24→去重→时效加权→取前 12→喂 LLM

#### `backend/memory.py`
- `_generate_insight_text()` 升级：新增「情感/恩怨」关键词模式（恨怨怒悲痛悔愧思念感激欢喜恩仇），每种模式备选 2~3 个随机模板，泛化模板从 2 种扩至 5 种
- 顿悟文本更自然多变，减少重复感

### 不影响
- Prompt Cache 架构：`reflect()` 和 `cross_reflect()` 均独立 LLM 调用，不与 talk_service.py 的缓存层交互
- API 端点：无接口变化
- 反思触发逻辑：阈值/最小间隔不变
