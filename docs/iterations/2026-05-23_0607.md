# 迭代记录：2026-05-23 06:07

## 改动概要

**🎮 游戏性 - 物品定价经济系统（Item Price Catalog & Economy Context）**

本轮为经济系统加入了完整的物品定价表，让 NPC 交易对话有据可依：

### 1. 物品定价表（ITEM_PRICE_CATALOG）

**问题**：LLM 自由编造金额，同一物品在不同 NPC 那里价差可达数十倍（如干粮时 5 文时 200 文），缺乏游戏经济的一贯性。

**方案**：
- `economy.py` 新增 `ITEM_PRICE_CATALOG`：25 种物品，分 5 大类（食/文/药/物/兵），各有基准价与说明
- `MAP_PRICE_MOD`：按地图差异的溢价/折扣倍率（荒野 +25%、佛寺 -20%、卡哨 +35% 等）
- `suggest_item_price(item, map_id)`：查询单物品当地价
- `format_economy_context(p)`：生成完整经济上下文，含当前地图行情、各类物品当地价、玩家随身物品估价

### 2. 对话引擎集成

**方案**：
- `talk_service.py` 动态层注入 `format_economy_context()`，在 `world_status_block` 之后、`vigor_status_block` 之前
- NPC 对话时自动获得当地物价基准，LLM 以此为底讨价还价（允许 ±50% 浮动，但禁止离谱定价）
- Prompt 中明确约束："如干粮卖 200 文就不合理"

### 3. Prompt Cache 架构保持

- 新增上下文注入在动态层（`dyn_parts`），不影响静态层 `cached_system()` 标记块
- 物价表数据在 `economy.py` 中，仅参与格式化，不修改 LLM Schema
