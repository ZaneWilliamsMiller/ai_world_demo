# 迭代记录 2026-05-26_0021

## 改动概要

### 💬 对话体验升级 — NPC 说话风格个性化（Speech Style Persona Enhancement）

**文件**：`backend/data/npcs_data.py`、`backend/models/npc.py`、`backend/services/talk_service.py`

**问题**：
NPC 拥有详细的角色卡（`character` 字段含「声口」），但：
1. 仅 8/16 个 NPC 定义了「声口」，其余 NPC 说话风格无引导
2. `format_npc_character_sheet()` 将「声口」与其他角色特质（所图、忌惮、隐痛等）混排，LLM 易忽略
3. Prompt 中无显式指令要求 LLM 遵守人物声口，导致对话风格趋同

**改进**：
1. **补全「声口」**：为缺失「声口」的 8 位 NPC 逐一撰写个性化说话风格描述（掌柜、牙人、皂隶、镖头、黑店、船家、里正、知客）
2. **强化提示词层级**：`format_npc_character_sheet()` 现将「声口」提取为 `★【说话风格——必须遵守】` 独立区块，置于角色底稿最上方
3. **静态层显式指令**：`talk_service.py` 在 `static_parts` 中加入 `【风格铁律】` 指令，要求 LLM 每一句台词和神态描写严格符合说话风格

**设计参考**：
- 角色一致性（Character Consistency）是 LLM 角色扮演的核心挑战
- 显式风格指令 + Prompt Cache 静态层 = 每轮对话都受约束，且不增加动态层 token 消耗
- 与现有「心境一致性记忆检索」形成「记忆-表达」双重个性化
