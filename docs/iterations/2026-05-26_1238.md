# 迭代记录 2026-05-26_1238

## 改动概要

新增**感知扫描系统**（🎮 游戏性）——玩家在危险地形附近会收到直觉预警，感知半径受天气和心气影响。

### 核心机制

- **感知半径**：基础 2 格
  - 雾天（重雾/薄雾/湿瘴）→ 半径 `-1`
  - 心气 < 40% → 半径 `-1`
  - 最终半径 ≥ 1 格
- **扫描目标**：危险地形 `~ ! @ ^` + 可疑地形 `I &`
- **叙事注入**：`danger_sense.alert` 字段随 API 响应下发，前端可直接渲染
