# 迭代记录 · 2026-05-23 02:50

## 本轮改动概要

### 前端交互优化

1. **WASD 手动移动 + 自动寻路双模式**
   - 按 M 键在"点击寻路"与"WASD 逐格"间切换
   - WASD/方向键可逐格步行，适合精细探索
   - 顶部栏显示当前模式（点击 / WASD）

2. **格子点击上下文菜单**
   - 点击相邻格：直接迈步（保持原有流畅体验）
   - 点击远格：弹出菜单，可选"自动寻路前往"或"向风闻子打探"
   - 菜单自动定位到地图区域，点击外部关闭

3. **向风闻子打探功能**
   - 点击远格 → 选"打探" → 自动向风闻子询问该位置的江湖传闻
   - 轻量 LLM 模式：max_tokens=450，不触发 NPC 反思，响应更快
   - 打探结果显示在对话日志中

4. **移动动画加速**
   - 逐格动画帧间隔：150ms → 80ms（提速 47%）
   - W/V/S 属性实时更新

### 后端性能优化

1. **LLM Token 预算压缩**
   - 普通对话：max_tokens 1200 → 800
   - 打探/问路：max_tokens 450（自动检测前缀）
   - 流式/非流式双通道均已适配

2. **动态奇遇改为后台异步**
   - `generate_dynamic_encounter()` 从阻塞 await 改为 `bg.add_task(_bg_encounter)`
   - 移动响应不再等待 LLM 奇遇生成，延迟从 11s → 瞬时
   - 新增 `_bg_encounter()` 后台函数，静默处理奇遇

### 文档与运维

1. **docs/iterations/ 迭代记录目录**
   - 每次迭代产出 `YYYY-MM-DD_HHMM.md`
   - 包含改动概要 + 文件变更表

2. **docs/PROJECT_STRUCTURE.md**
   - 完整项目结构说明：backend/、static/、docs/ 每个文件的作用

3. **定时任务优化**
   - 频率：每 2 小时 → 每 6 小时
