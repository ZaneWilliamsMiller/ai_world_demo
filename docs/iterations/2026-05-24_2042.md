## 问题发现

前端 `getLocationInfo()` 和格子点击处理器缺少地形通行校验：

1. `getLocationInfo()` 始终返回 `walkable: true`，无论地形是否为墙(#)、悬崖(^)、裂隙(!) 等不可通行格
2. 点击事件代理未过滤 `disabled` 状态，用户可点击城墙格触发 `doWalk`（虽然后端会拒绝，但前端给了虚假的操作感）
3. 点击菜单中"自动寻路前往"也未检查 `walkable`

## 改动内容

### `static/map.js`

**① `getLocationInfo()` 增加真实通行判断**
```js
const UNWALKABLE = new Set(["#", "^", "!"]);
const DANGER_SET = new Set(["~", "!", "@", "^"]);
const walkable = !UNWALKABLE.has(ch);
return { ...walkable, dangerous: DANGER_SET.has(ch) };
```

**② `UNWALKABLE_SET` 引入 renderMap**
```js
const UNWALKABLE_SET = new Set(["#", "^", "!"]);
// 墙/悬崖/裂隙格：disabled + tile-unwalkable 样式
btn.disabled = !canStep || UNWALKABLE_SET.has(ch);
if (UNWALKABLE_SET.has(ch)) btn.classList.add("tile-unwalkable");
```

**③ 点击事件代理新增 disabled 过滤**
```js
if (!btn || !host.contains(btn) || btn.disabled) return;
```

### `static/game.css`

**`.tile-unwalkable` 样式**
```css
.tile-unwalkable {
  opacity: 0.45;
  cursor: not-allowed !important;
  pointer-events: none;
}
```
