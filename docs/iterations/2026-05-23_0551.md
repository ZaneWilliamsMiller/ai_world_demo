# 迭代记录：2026-05-23 05:51

## 改动概要

**🧠 NPC 大脑升级 - 计划对照反思 + 情绪驱动反思加速**

本轮针对 NPC 反思系统的两个关键增强：

### 1. 计划对照反思（Plan-Aware Reflection）

**问题**：NPC 每日计划由 LLM 生成了，但在反思时从未被引用——NPC 无法对照「原计划」与「实际发生」产生洞察。

**方案**：
- 在 `agent_brain.py` 的 `reflect()` 和 `cross_reflect()` 中注入当日计划上下文
- 新增 `memory.py::format_plan_for_reflection()` 格式化计划为反思专用上下文
- 反思时 NPC 会对比「计划做什么 vs 实际发生了什么」，产生懊悔/庆幸/调整等更丰富的人性化洞察

### 2. 情绪驱动反思加速（Emotion-Driven Reflection Urgency）

**问题**：反射阈值固定为 35，不随情绪变化。NPC 在极端情绪下（大喜大悲、极度警觉）与平静时以相同速率触发反思。

**方案**：
- `AgentMind._emotion_adjusted_reflect_threshold()`：效价极值最大可将阈值从 35 降至 18；唤醒度极值再降 5；最低 13
- 情感锚点创建时直接加速：`importance_since_reflect += ANCHOR_IMPORTANCE * 1.5`
- 效果：NPC 在情绪巨变后更快自省，让反思时机更符合人性

### 3. Prompt Cache 架构保持

- 所有改动仅在 agent_brain.py（反思调度）、memory.py（数据模型）、talk_service.py（情绪演化）中
- 未修改 talk_service.py 的静态/动态分层结构
- `cached_system()` 标记的静态块不受影响
