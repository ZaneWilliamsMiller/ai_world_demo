## 改动概要

此前 `/api/npc/talk` 和 `/api/npc/talk_stream` 两个对话端点中，若 LLM API 调用持续失败（重试耗尽），直接抛出 HTTP 502 错误——玩家看到的是冰冷的 JSON 报错而非 NPC 回应，游戏体验等同崩溃。

本轮引入**优雅降级机制**：LLM 失败时 NPC 做出自然的「走神/分心」表现，对话流程不中断，同时后台日志完整记录供运维排查。

### 核心改动

1. **`talk_service.py`** 新增 `build_graceful_fallback()` 函数，内置 7 条拟人化降级话术池，随机抽取；生成合法的 `NpcResponseSchema` 供下游无感知消费
2. **`routes.py` `/api/npc/talk`** 将原来的 `raise HTTPException(502)` 替换为 `build_graceful_fallback()` 调用，返回标准 NPC 对话响应格式，并在响应中添加 `llm_fallback: true` 标记
3. **`routes.py` `/api/npc/talk_stream`** 同样降级替代 `fatal: true` 错误终止，逐段推送降级文本维持流式观感，不白屏
4. 降级响应不触发 `bg_reflect` 后台反思任务（无实质内容可反思）
5. 两种路径均通过 warning 级别日志记录原始错误信息

### 降级话术池

7 条话术随机选取，覆盖「走神」「被旁人打断」「深夜倦极」「风/喧哗引开注意」「欲言又止」等江湖日常：

- （似乎神游天外，一时未能回话……）
- （忽被旁人打断，未及应答）
- （夜色沉沉，此人似已倦极，摆了摆手）
- （一阵风吹过，对方像是没听清你说了什么）
- （那人低头想着心事，半晌才回过神来）
- （远处忽然起了喧哗，他的注意力被引开了）
- （灯火摇曳，对方欲言又止，终究没说什么）

### 架构影响

- **Prompt Cache 不受影响**：降级路径在 LLM 调用之后介入，不涉及 `cached_system()` 路径
- **状态一致性**：`apply_npc_reply()` 在降级态下仍被调用（基于空 `NpcResponseSchema`），确保对话历史写入、时辰推进、自动存档等流程不中断
- **前端兼容**：`llm_fallback: true` 字段为增量字段，前端可忽略或展示特殊提示
