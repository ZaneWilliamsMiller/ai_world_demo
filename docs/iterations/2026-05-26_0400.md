# 迭代记录 — 2026-05-26 04:00

## 改动概要

**经济上下文分层注入** — 优化 `format_economy_context` 输出策略，区分商贩 NPC 与非商贩 NPC。

### 问题

此前 `format_economy_context()` 对**所有 NPC**（包括风闻子、镖头、皂隶等非商贩角色）注入完整的逐品价格目录（~200-300 tokens），这些 NPC 并不参与交易，价格目录对对话无实质帮助，反而增加 token 消耗和 LLM 推理延迟。

### 方案

`format_economy_context(p, vendor_npc_id=npc_id)` 新增 `vendor_npc_id` 参数：
- **商贩 NPC**（zhanggui/yaren/yulaog/lizheng/lika/seng/yizu）→ 完整价格目录（逐品本地价，行为不变）
- **非商贩 NPC**（其他所有 NPC）→ 仅行情摘要（地点倍率、天气浮动、玩家随身估价，不含逐品目录）

非商贩仍能感知物价趋势（"今日雨大货贵"），但不逐品罗列，对游戏性无损且更聚焦角色本职。

### 技术细节

- `format_economy_context` 参数签名从 `(p: PlayerState)` 扩展为 `(p: PlayerState, vendor_npc_id: str | None = None)`，向后兼容
- 通过 `vendor_npc_id in NPC_INVENTORY_SEEDS` 判断是否为商贩
- 仅在 `talk_service.py` 一处调用，通过 `build_npc_messages` 透传 `npc_id`
