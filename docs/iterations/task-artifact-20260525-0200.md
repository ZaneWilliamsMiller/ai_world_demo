### 改进内容
在 `backend/services/agent_service.py` 的 `bg_reflect` 中添加夜间门禁：

**核心逻辑：**
- 世界时辰为子时(0)、丑时(1)、寅时(2) → 自动反思跳过
- 例外：NPC 情绪唤醒度 ≥ 8.0 时即使在夜间也允许反思（模拟失眠/夜不能寐）
- 跳过时输出 debug 日志

**设计理由：**
1. Token 节省：子时-寅时占全天 1/4，跳过可减少 ~25% 自动反思 LLM 调用
2. 叙事合理：深夜 NPC 自省与休眠状态冲突
3. 情感真实：极端唤醒度例外保留「夜不能寐」的戏剧性叙事
4. 低侵入性：仅修改 bg_reflect 自动路径，手动 /api/agent/reflect 不受影响
