# 活纸每日迭代 · 2026-05-25 00:12

## 改动概要

**方向**：🧠 NPC 大脑升级 — 反思时引入结构化「计划-观察偏差分析」

**问题**：`reflect()` 虽有 `format_plan_for_reflection()` 把 NPC 当日计划注入 prompt，但未做任何结构化对比分析。LLM 需要在大量上下文里自行"悟出"哪些计划有进展、哪些被搁置，反思质量依赖 LLM 悟性。

**改进**：新增 `_plan_deviation_analysis()` 启发式函数，在反思前对每条计划项提取关键词，在近期观察中搜索覆盖情况：
- 关键词覆盖率 ≥ 30% → 标记为「有迹可循」
- 不达标 → 标记为「未见踪影」
- 结果以结构化偏差摘要注入 reflect prompt，让 LLM 有明确的对比基础

**设计取舍**：
- 纯启发式（零 LLM 开销），不增加 API 调用
- 分析结果仅供 LLM 参考，不强制输出格式
- 最多展示 3 项匹配 + 3 项不匹配，避免 prompt 膨胀
