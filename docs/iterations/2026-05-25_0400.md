> 时间：2026-05-25 04:00 (Asia/Shanghai)

> 关键词：mood-congruent memory, 情感一致性偏差, 记忆检索

## 改动概要

在 `memory.py` 的 `retrieve()` 函数中引入**心境一致性记忆检索偏差**（mood-congruent memory bias）。

### 背景

人类心理学研究发现，情绪会扭曲记忆检索——愤怒的人更容易记起旧怨，欣悦的人更容易想起好事。这是"心境一致性记忆"（mood-congruent memory）效应。此前 NPC 的记忆检索完全基于 recency/importance/relevance 三项客观指标，未考虑检索时的情绪状态。

### 改动内容

1. **新增 `_sentiment_hint(text)` 函数**：基于关键词匹配，返回 -1.0（全负面）~ +1.0（全正面）的记忆文本情感倾向估值。

2. **新增心境一致性常量**：
   - `_MOOD_BIAS_THRESHOLD = 3.0`：效价绝对值超过此阈值才启用偏差（避免微弱情绪干扰）
   - `_MOOD_BIAS_WEIGHT = 0.18`：心境偏差在检索总分中的最大权重
   - `_POSITIVE_MEMORY_WORDS` / `_NEGATIVE_MEMORY_WORDS`：正/负向情感词库

3. **修改 `retrieve()` 函数**：
   - 检索前检测 NPC 当前 `affect_valence`，若 `|valence| >= 3` 则启用偏差
   - 对每条记忆调用 `_sentiment_hint()` 获取情感倾向
   - 计算 `mood_congruence = sentiment * (valence / 10)`：情感极性一致时为正
   - 将 `mood_congruence * _MOOD_BIAS_WEIGHT` 加入 bonus，微调检索排名

### 效果

- 愤怒 NPC（valence=-7）检索时，负面记忆排位微幅提升 → 更可能回忆起旧怨，对话带刺
- 欣悦 NPC（valence=+7）检索时，正面记忆更易浮起 → 更可能想起好事，对话温煦
- 平静 NPC（|valence| < 3）不受影响，保持原有检索行为
