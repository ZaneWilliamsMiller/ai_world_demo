## 本轮改动概要

### 上下文感知的记忆检索（Contextual Memory Retrieval）

**问题**：NPC 记忆检索（`mem.retrieve()`）仅使用玩家当前消息作为查询词。当玩家用指代词（如「那件事后来怎样了」「接着说」）时，检索命中率极低，导致 NPC 无法回忆刚才聊到的旧事，对话连贯性打折。

**解决方案**：新增 `build_retrieval_query()` 函数，在 `memory.py` 中实现：
1. 从最近4轮对话历史中抽取实体关键词（人名、地名、物品名、事件名）
2. 检测玩家最近的未完结提问
3. 将话题关键词拼接到当前消息中，形成复合检索查询
4. 检索数量从 k=5 提升到 k=8（因查询更丰富）

**设计取舍**：
- 纯本地启发式，零 LLM 调用开销（与 Prompt Cache 架构一致）
- 关键词白名单覆盖 40+ 游戏实体词（人物、地点、物品、事件）
- 不改变现有内存结构，仅增强检索查询质量
- 保留原有 `format_topic_thread` 独立功能（对话连贯性提示词注入）
