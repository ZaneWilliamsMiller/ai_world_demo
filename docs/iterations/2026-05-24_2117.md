## 改动概要

**方向**：🎮 游戏性（地图交互）

**问题**：上一轮迭代 (549f278) 将不可通行地形（`#` 墙、`^` 悬崖、`!` 裂隙）设为完全不可点击 (`btn.disabled` + CSS `pointer-events: none`)，导致玩家无法点击这些格子上的 NPC（如风闻子）进行交谈或打探。

**修复**：恢复不可通行格子的可点击性，由前端逻辑区分"不可步行"与"不可交互"，确保玩家可以：
- 点击不可通行格子 → 弹出菜单，内含「向风闻子打探此地」
- 如果格子有 NPC → 额外显示「与[NPC名称]交谈」
- 如果格子可通行 → 同时显示「自动寻路前往」
- 相邻不可通行格有 NPC 时 → 直接触发交谈
