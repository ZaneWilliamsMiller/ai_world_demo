# 活纸·每日迭代 — 2026-05-24_0602

## 方向
🎮 游戏性 — NPC 状态动态演化（声望/好感驱动的态度记忆）

## 改动概要

### 问题
NPC 的行为状态（idle/resting/alert/hostile）此前**仅由时间驱动**：
- `update_npc_states_from_habits()` 根据时辰和 NPC 作息切换 idle↔resting
- 玩家的声望、好感、过往冲突对 NPC 的态度**零影响**

这意味着一个在绿林声望 -50、被全江湖通缉的玩家，白天遇到的 NPC 依然笑脸相迎（idle），世界缺乏因果感。

### 改进

#### `backend/systems/core.py`
- 新增 `update_npc_state_dynamic(p, npc_id)`：基于三项因素动态判定单个 NPC 对玩家的态度
  - 势力声望 ≤-25 或 个人好感 ≤-30 → **hostile**（敌视）
  - 势力声望 ≤-8 或 个人好感 ≤-8 或 正在与 ta 周旋险局 → **alert**（警觉）
  - 关系恢复后自动回退到 idle（让时间驱动接管）
- 新增 `update_all_npc_states_dynamic(p)`：对全部非隐藏 NPC 执行动态评估，在移动后调用以刷新前端状态图标
- `npc_state_for_dialogue()` 增强：alert/hostile 状态附加声望/好感溯源文字（如「此人在绿林道里声名狼藉」），让 LLM 知道 NPC 为什么提防/敌视玩家

#### `backend/services/talk_service.py`
- `build_npc_messages()` 开头调用 `update_npc_state_dynamic(p, npc_id)`，确保每次对话前 NPC 状态反映最新声望/好感
- **不影响 Prompt Cache 架构**：状态更新在静态块组装之前完成，不改变 cached_system 内容

#### `backend/api/routes.py`
- 移动处理器中，`update_npc_states_from_habits()` 之后调用 `update_all_npc_states_dynamic()`，让前端实时显示 NPC 态度图标

### 设计原则
- 时间驱动（作息）与上下文驱动（态度）**分层叠加**，互不干扰
- 零 LLM 调用，纯算术判定，无性能开销
- 态度可逆：声望/好感改善后 NPC 自动恢复中立
