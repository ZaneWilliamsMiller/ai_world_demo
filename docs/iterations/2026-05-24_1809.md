## 改动概要

**🐛 Bug 修复 - 经济系统健壮性：suggest_item_price 未定义变量 + NPC 货柜增量初始化**

### 1. `suggest_item_price` 函数修复未定义变量 `map_id`

**问题**：`suggest_item_price()` 返回值的 `market_hint` 字段引用了未定义的局部变量 `map_id`，任何访问该字段的调用方都会触发 `NameError`。

**根因**：该函数签名接受 `player: Any` 参数，但 `market_hint` 构造时使用了不在作用域内的 `map_id` 标识符（疑似复制粘贴遗留）。

**修复**：
- `market_hint` 改为基于已有 `map_hint`（来自 `zone_price_mod` 的返回值）动态生成
- 从 `player.map_id` 安全提取地图 ID（`getattr` 兜底）
- 提示格式：`"{map_hint}，{物品名}当地约{local}文（基准{base}文）"`

### 2. `init_npc_inventories` 增量初始化

**问题**：`init_npc_inventories()` 使用 `if p.npc_inventories:` 作为全量初始化判断。当老存档已有部分 NPC 货柜（但缺少后续新增商贩）时，新增商贩不会被补齐。

此外，`npc_inventories` 和 `npc_inventory_restock_day` 字段在 `None` 值时（反序列化异常）会跳过初始化。

**修复**：
- 改为逐 NPC 判断：已存在于 `p.npc_inventories` 中的保留不动（不覆盖交易后的真实库存），不存在的补齐为种子库存
- 新增 `None` 值兜底：字段为 `None` 时重建为空 dict
- 同步补齐 `npc_inventory_restock_day` 追踪（缺失的 NPC 初始化为当前世界日，避免立即触发补货）
